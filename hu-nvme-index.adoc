= 了解如何使用 NVMe-oF 設定 ONTAP SAN 主機
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
您可以設定支援的 SAN 主機，使其使用 NVMe over Fabrics （NVMe-oF） 協議，並將 ONTAP 作為儲存目標。NVMe-oF 包括 NVMe over Fibre Channel （NVMe/FC） 和 NVMe over TCP （NVMe/TCP）。根據主機作業系統 （OS） 和 ONTAP 版本，您需要在主機作業系統上設定並驗證 NVMe/FC 或 NVMe/TCP 協議，或同時設定並驗證兩者。
