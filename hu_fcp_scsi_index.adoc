= 了解如何使用 FCP 和 iSCSI 設定 ONTAP SAN 主機
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
您可以為某些 SAN 主機作業系統 (OS) 配置 FCP 和 iSCSI，並將 ONTAP 作為目標。如果您的主機作業系統受 SAN Host Utilities 軟體支援，則首先需要安裝對應的作業系統主機公用程式套件，其中包含 SAN 工具套件。然後，針對所有主機作業系統類型，設定 ONTAP LUN 的多路徑設定。
